🖥️ A Interface do Builder

Abaixo estão os detalhes de cada campo da sua ferramenta de compilação:

1. NOME DO PROJETO:

Define o nome do arquivo .exe e o nome que aparecerá no Instalador Windows. Ex: MeuApp_VersaoFinal

2. ARQUIVO HTML PRINCIPAL:

O arquivo base (index.html). O Builder coletará automaticamente todos os arquivos JS/CSS que estiverem na mesma pasta.

3. ÍCONE DO PROGRAMA (.ICO):

Deve ser um arquivo de imagem no formato .ico. Ele será o rosto do seu aplicativo.

4. PASTA DE DESTINO:

Local onde o Builder criará a pasta final do sistema e os instaladores.

5. GERAR INSTALADOR PROFISSIONAL:

Se marcado, cria um arquivo Setup.exe para que o cliente instale o programa como um software oficial.

🟢 Botão Gerar Tudo Agora

Ao clicar no botão verde, o Builder inicia o processo. Não feche a janela até que o Log de Processamento mostre a mensagem de sucesso.

📝 Log de Processamento

Acompanhe em tempo real cada etapa da compilação. Caso ocorra algum erro, as informações detalhadas aparecerão nesta área preta.

Fluxo de Compilação

O Studio Builder utiliza o motor PyInstaller + Inno Setup para garantir que seu código HTML seja convertido em binários seguros e otimizados para Windows 10 e 11.

📂 Estrutura de Saída

O Builder gerará uma pasta com o nome do seu projeto contendo:

  • SeuApp.exe (O programa principal)
  • _internal/ (Pasta de dependências vitais)
  • Instaladores/ (O instalador .exe de setup)

🔔 Dica da Bandeja

Lembre-se: Após compilado, seu app se esconde na bandeja ao ser fechado. Isso mantém o sistema leve e sempre pronto para uso rápido.
